# Audio Folder Unifier — Build Checklist

The build plan in sessions. Start a session with "lets do Session N from checklist.md". At the end of each session: tick off what's done, write the session's notes to `docs/session-notes/sessionN.md` (add a row to its `INDEX.md`; read past notes only when relevant), and print the copy-paste prompt for the next session.

Each session leaves the program in a runnable state. Specs: `docs/INDEX.md` (overview), `docs/gui_spec.md`, `docs/processing_spec.md`, `docs/presets.md`. Decisions: `docs/closed-questions.md`.
