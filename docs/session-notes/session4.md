# Session 4 — GUI

**Session 4 (2026-11-09):** the real window, on `core.pipeline` and `core.effects`. `gui/theme_preview.py` is gone (moved to `C:\trash\afu_session4\`).
- **Files:** `gui/app.py` (window, header/footer, helpers, close handler), `gui/sections.py` (sections 1-4, every control bound to its `config.json` key through `_var()`), `gui/jobs.py` (Start/Stop, progress area, log, worker thread + `queue.Queue` + `root.after(100)` polling). The two new files are mixins on `App`, which keeps every file under the 500-line limit (jobs.py is the biggest at ~320).
- **The scan runs on its own when a From folder is picked** (or To / subfolders change, or at startup for the remembered folder). Otherwise "Only fix the unusually quiet files" could never be ticked before the first run, since it's greyed until a scan finds some. Start during the scan waits for it and then runs. Start reuses the scan unless the folder's file list changed. Written into `docs/gui_spec.md` → Section 4.
- **One worker at a time, one `FFmpegRunner`**, `reset()` before each job. Picking another folder during a scan cancels it and starts a new one when the old worker ends. Every message is stamped with a job number, so leftovers from a finished job are ignored. Controls are greyed during a batch but not during a scan. Closing the window cancels the job and waits up to 5 s so the temp folder gets deleted.
- **Height rechecked:** `winfo_reqheight()` 943 (960 leaves 17 px; at the 920 minimum the log keeps ~3 lines). Two fixes: the effect description box went from 4 to 3 lines (the longest is 3 at the 860 minimum width), and both `tk.Text` widgets got `width=1` (their default 80 characters made the window need 870 px of width).
- **Dropdown capped at 15 rows:** with all 23 it opened upwards off the top of the screen.
